# simple Interest Calculator

A simple Bash script to calculate simple interest based on the principal amount, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

## Input

The calculator takes the following inputs from the user:

- Principal amount
- Rate of interest
- Time period

## Usage

Run the `simple-interest.sh` Bash script and enter the requested values when prompted.

## Example

For a principal amount of 1000, rate of interest of 5%, and time period of 2 years:

Simple Interest = (1000 × 5 × 2) / 100

Simple Interest = 100
